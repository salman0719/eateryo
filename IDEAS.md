# IDEAS.md — possible future features

Ideas we might implement later. This is a parking lot, not a plan:
`ROADMAP.md` stays the build order and `PHASE-2.md` the current scope —
an idea graduates by being scoped into those docs.

## First run / onboarding

- **Make the first run a performance** — a signed-out browser with no drafts
  gets a staged, animated Capture experience instead of the standard form:
  an opening beat, photos that visibly turn into a menu while the real
  extraction runs, a review pass that reacts as items are checked, and a
  finish line that hands the visitor straight to publish or share. Each step
  is its own scene with motion and sound-off-friendly feedback, not a static
  screen. Returning browsers, account holders, and anyone with a draft keep
  the quiet flow. It must stay skippable, honour reduced motion, and never
  fake extraction progress or invent menu content — the theatre frames the
  real request, it does not replace it.

## Routing / URLs

- **Refresh-proof capture flow** — persist the capture flow state in the
  URL so a refresh doesn't lose the upload step.
